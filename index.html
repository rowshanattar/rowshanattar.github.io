01 — about
Who I am

I'm a Data/ML Engineer with a computer science background and a soft spot for systems that learn. My path started in network security and then later DevOps — building CI/CD pipelines, containerizing apps with Docker and Kubernetes, and keeping infrastructure alive — before I moved deeper into data and machine learning.

I love building agents for all kinds of tasks — most recently an AI agent in JavaScript with YouGov API integration that lets the marketing team run their own data queries. I'm a big fan of automation pipelines and enjoy working with GitHub Actions and Azure DevOps.

And I'm into deep learning — in both senses. The AI kind, and the kind where I dig until I really understand something: why is it called a pull request and not a push request? What actually happens when an IDE runs my code, and how is that different from a plain text editor? I love chasing those "wait, but why?" questions all the way down.

I would like to describe myself as a DevOps/DataOps/MLOps Engineer, life is just much more fun when you are an ENGINEER!
