What is a Kalman Filter?

A Kalman Filter (KF) is a combination of mathematical equations that can estimate the state of variables at arbitrary points in time. It's especially useful when real-time data isn't continuously available but is still needed — when there's no information between discrete data points. The KF helps fill those gaps and gives us an understanding of how the available data points connect. Under the assumption of Gaussian noise and a linear system, the KF provides the mathematically optimal estimate.

The KF needs to know how each variable should change as time passes:

Xnew = A · Xold A is a matrix describing how X changes over time

For example, if X is the temperature of a closed system, then by knowing the relevant heat law we can set A based on that rule (e.g. A = [0.03]). The KF also assumes that no model is perfect, so it adds a noise term Q to its prediction.

Another responsibility of the KF is to fold in real-world data — measurements arriving through sensors — into its belief. Whenever a new measurement arrives, the KF uses it to update (correct) all the variables. Just as the model has noise, each measurement carries a measurement noise term R. The more noise a measurement has, the less the KF trusts it, which results in a smaller K (the Kalman gain, explained below) — meaning the filter leans more heavily on its own model prediction.

There's also a matrix P, the uncertainty matrix, which keeps track of the uncertainty for each variable. The more iterations that pass without a real-world measurement, the larger P grows; with each correction step, P shrinks.

The two phases

Each iteration the KF either predicts (no new data) or corrects (a measurement arrived).

Prediction step — when no new data is available, the KF predicts and updates the variables, and grows the uncertainty:

Xnew = A · Xold
Pnew = A · Pold · Aᵀ + Q

Correction step — as soon as a measurement Z arrives, the KF corrects its estimate:

Xnew = Xold + K · ( Z − H · Xold ) H is the observation matrix

The observation matrix H is all 1s if we measure the parameter directly. If not, H carries the conversion. For example, if we measure temperature in Celsius but the rest of our equations work in Fahrenheit, H contains that conversion formula.

Finally, the Kalman gain K is responsible for balancing between the measurement and the prediction:

K = P · Hᵀ · ( H · P · Hᵀ + R )⁻¹

So if R — the measurement noise — is high, then K becomes small, and the KF relies more on its own model prediction. That single balancing act is the heart of why the Kalman Filter works so well.
